# Sever 실행 파일 안내

Sever는 요청된 폴더 이름입니다. app.py, requirements.txt, modules/와 README.md, 폴더관리지침을 보관합니다. 실행하려면 관리용/2026-11-17/Study_Python 사본을 app.py와 같은 위치의 Study_Python으로, Answer 사본을 Study_Python_Answer로 배치합니다.

pip install -r requirements.txt 후 streamlit run app.py를 실행합니다.

최초 기준본의 파일 목록과 커밋은 baseline-2026-11-17 압축본의 매니페스트를 따릅니다. 과거 패치·Git bundle·Windows 배포 묶음은 사용하지 않습니다.
